# Tietosuojalain (1050/2018) kommentaari

Kommentaari suomalaiseen säädökseen: **Tietosuojalaki 5.12.2018/1050**. Kommentaari kattaa **38 pykälää** (1–6 luku, mukaan lukien voimaantulo- ja siirtymäsäännökset) **2 kommentaarin luvussa**; kunkin pykälän kohdalla esitetään säännöksen sanamuoto sellaisenaan ja sen jälkeen kommentaari.

Tekstin tila: Finlexin ajantasainen lainsäädäntö (ajantasaistettu **27.6.2025**). Lähdetekstiin ei sisälly muutossäädösmerkintöjä.

## Sisällysluettelo

Ks. [INDEX.md](INDEX.md). Menetelmän kuvaus on tiedostossa [00-johdanto.md](00-johdanto.md).

## Menetelmä

Kommentaari on laadittu **yksinomaan paikallisten aineistojen perusteella** (Finlexin avoimen datan ajantasainen säädösteksti), ilman kaupallisia oikeudellisia tietokantoja. Säännösten sanamuoto on siirretty lähteestä koneellisesti ja sanatarkasti. **Oikeuskäytäntö ei sisälly tähän versioon** — se lisätään erillisessä vaiheessa.
